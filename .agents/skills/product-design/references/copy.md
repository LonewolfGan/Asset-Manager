# Product Copy Reference

Rules for user-facing language, labels, and CTAs.

## CTA Rules
- **Destructive Actions**: Always use `Verb + Noun` (e.g. "Delete Project", "Remove Member"). NEVER use generic words like "Confirm", "OK", or bare "Delete".
- **Action Labels**: Use active, explicit verbs (e.g. "Create Invoice", "Save Changes", "Send Invite").
- **No Filler Text**: Eliminate AI slop descriptions like "(optionnel - visible par le client)". Keep microcopy direct, clear, and natural.
- **Accessible Names**: All icon buttons and form inputs MUST have an explicit `aria-label` or `<label>`.
