MIGRATION BACKEND COMPLÈTE — EVERYDAYTOOLS HUB
Objectif : abandonner tout traitement côté client et construire un backend
haute-performance qui rende cette plateforme meilleure que TinyPNG,
iLovePDF, Smallpdf et Squoosh réunis.

═══════════════════════════════════════════════════════════════
ÉTAT ACTUEL DU PROJET
═══════════════════════════════════════════════════════════════

Stack :
- pnpm monorepo, Node 24, TypeScript 5.9
- Frontend : React + Vite → artifacts/everydaytools/ (port 5000)
- API : Express 5 → artifacts/api-server/ (port 8080)
- Vite proxie /api → 8080 (déjà configuré dans vite.config.ts)
- Tous les outils tournent actuellement côté client (Canvas API, pdf-lib,
  mammoth, tesseract.js, etc.) — TOUT doit migrer vers le backend

Problème actuel concret :
- image-compress.tsx : Canvas toBlob() AUGMENTE la taille (94.2 KB → 213.1 KB)
  car PNG/JPEG ne sont pas vraiment optimisés par le navigateur
- word-to-pdf : qualité médiocre (html-to-image au lieu d'un vrai renderer)
- pdf-compress : pdf-lib ne fait pas de vraie compression

ARCHITECTURE CIBLE
═══════════════════════════════════════════════════════════════

Frontend React :
- Envoie le fichier via multipart/form-data POST /api/tools/<outil>
- Affiche ToolLoadingState avec Server-Sent Events ou polling de progression
- Reçoit le fichier traité en réponse binaire et le propose au téléchargement
- ZÉRO traitement local : plus de Canvas API, pdf-lib, mammoth côté client

Backend Express (artifacts/api-server/) :
- Toutes les routes sous /api/tools/
- Traitement en mémoire (multer memoryStorage) — jamais d'écriture disque sauf /tmp
- Nettoyage immédiat après chaque réponse (finally block)
- Rate limiting : 20 req/min/IP (utils/rate-limit.ts déjà existant)
- Validation MIME réelle (magic bytes) avant traitement
- Timeout 60s par job pour éviter les blocages

```typescript
import { Router, Request, Response } from 'express';
import multer from 'multer';
import sharp from 'sharp';

const router = Router();
const upload = multer({
  storage: multer.memoryStorage(),
  limits: { fileSize: 50 * 1024 * 1024 }, // 50MB
});

// Validation MIME réelle (magic bytes)
function detectMime(buffer: Buffer): string | null {
  const sig = buffer.slice(0, 12);
  if (sig[0] === 0xFF && sig[1] === 0xD8) return 'image/jpeg';
  if (sig[0] === 0x89 && sig[1] === 0x50 && sig[2] === 0x4E) return 'image/png';
  if (sig[0] === 0x52 && sig[8] === 0x57 && sig[9] === 0x45) return 'image/webp';
  if (sig[0] === 0x25 && sig[1] === 0x50 && sig[2] === 0x44) return 'application/pdf';
  // Ajouter d'autres signatures selon besoin
  return null;
}

router.post('/image-compress', upload.single('file'), async (req, res) => {
  try {
    if (!req.file) return res.status(400).json({ error: 'No file uploaded' });
    
    const input = req.file.buffer;
    const mime = detectMime(input) ?? req.file.mimetype;
    const quality = parseInt(req.query.quality as string) || 82;
    
    let sharpInstance = sharp(input);
    let output: Buffer;
    let outMime: string;
    
    if (mime === 'image/jpeg') {
      output = await sharpInstance.jpeg({ quality, mozjpeg: true }).toBuffer();
      outMime = 'image/jpeg';
    } else if (mime === 'image/png') {
      output = await sharpInstance.png({ compressionLevel: 9, palette: true }).toBuffer();
      outMime = 'image/png';
    } else if (mime === 'image/webp') {
      output = await sharpInstance.webp({ quality, effort: 6 }).toBuffer();
      outMime = 'image/webp';
    } else {
      output = await sharpInstance.jpeg({ quality: 82, mozjpeg: true }).toBuffer();
      outMime = 'image/jpeg';
    }
    
    // Règle absolue : jamais retourner un fichier plus lourd
    const finalBuffer = output.length < input.length ? output : input;
    const gain = Math.round((1 - finalBuffer.length / input.length) * 100);
    
    res.set({
      'Content-Type': outMime,
      'Content-Length': finalBuffer.length,
      'X-Original-Size': input.length,
      'X-Compressed-Size': finalBuffer.length,
      'X-Compression-Gain': gain,
      'Content-Disposition': `attachment; filename="compressed_${req.file.originalname}"`,
    });
    res.send(finalBuffer);
  } catch (err) {
    res.status(500).json({ error: err instanceof Error ? err.message : 'Compression failed' });
  }
});

export default router;
