PART 3 — ANALYTICS (Plausible)
Use Plausible Analytics — it is privacy-friendly (GDPR compliant, no cookies, no consent banner needed), lightweight (< 1KB script), and free to self-host.
3a. Install Plausible
Add to the <head> of every page:
html<script defer data-domain="yourdomain.com" src="https://plausible.io/js/script.js"></script>
If self-hosting: replace the src with your Plausible instance URL.
3b. Custom events — track tool usage
Track when users actually use each tool (not just visit the page):
javascript// When a file is successfully processed and download is triggered
window.plausible('Tool Used', {
  props: {
    tool: 'compress-pdf',
    category: 'pdf',
    file_type: 'application/pdf',
    // do NOT log file name or content — privacy
  }
})

// When an error occurs
window.plausible('Tool Error', {
  props: {
    tool: 'compress-pdf',
    error_type: 'file_too_large', // generic category, not user data
  }
})

// When user switches language
window.plausible('Language Changed', {
  props: { language: 'fr' }
})
Create a utility function so all tools use the same tracking call:
javascript// /src/utils/analytics.js
export const trackToolUsed = (toolSlug, category) => {
  if (typeof window.plausible !== 'undefined') {
    window.plausible('Tool Used', { props: { tool: toolSlug, category } })
  }
}

export const trackToolError = (toolSlug, errorType) => {
  if (typeof window.plausible !== 'undefined') {
    window.plausible('Tool Error', { props: { tool: toolSlug, error_type: errorType } })
  }
}
Wire trackToolUsed into every tool's download/success handler. Wire trackToolError into every tool's error handler.

Which languages are most used
Top pages by traffic
