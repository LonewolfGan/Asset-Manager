CONTRAST ENFORCEMENT — no exceptions:
  Every text/background combination must pass WCAG AA (4.5:1 normal, 3:1 large).
  Before assigning any color pair, verify contrast mentally:
    --text-primary on --bg-base:     PASS (both themes)
    --text-primary on --bg-surface:  PASS
    --text-primary on --bg-hover:    PASS ← critical — hover must never hide text
    --text-secondary on --bg-base:   PASS
    --text-secondary on --bg-hover:  PASS ← verify explicitly
    --accent-text on --accent:       PASS
  NEVER apply --text-secondary or --text-tertiary on --bg-hover.
  On hover, text color stays the same or shifts TOWARD --text-primary, never away.
  Hover state changes ONLY: background-color. Nothing else.

ACCENT RULES:
  ✓ Primary button background
  ✓ Progress bar fill
  ✓ Active nav indicator (2px underline)
  ✓ Focus ring (outline: 2px solid, 40% opacity)
  ✗ Never as text color on dark bg
  ✗ Never on more than one element per viewport
  ✗ Never decorative

HOMEPAGE TOOL GRID
───────────────────────────────────────────────

Each ToolCard:
  bg: var(--bg-surface)
  border: 1px solid var(--border)
  border-radius: 8px
  padding: 20px 24px
  display: flex, flex-direction: column, gap: 8px

  Structure inside card:
    <span class="tool-category"> — e.g. "Document" — text-xs, all-caps,
      letter-spacing 0.08em, color var(--text-secondary)
    <h2> tool name — text-lg, font-weight 500, color var(--text-primary)
    <p> one-line description — text-sm, color var(--text-secondary)
    <div class="tool-formats"> — inline list of format tags if applicable
      each tag: bg var(--bg-elevated), border-radius 3px, padding 2px 6px,
      font-size 0.7rem, font-family mono, color var(--text-secondary)

  Hover state:
    bg → var(--bg-hover)
    border-color → var(--border-strong)
    transition: background 120ms ease, border-color 120ms ease
    IMPORTANT: ALL text inside the card remains var(--text-primary) and
    var(--text-secondary) respectively. No color change on any child element.
    No transform. No shadow. No scale.

  The entire card is a single <a> tag wrapping all content.
  No nested interactive elements inside cards.

Group cards by category with a category label above each group:
  <h2 class="category-label"> — text-xs, all-caps, letter-spacing 0.08em,
  color var(--text-tertiary), padding-bottom 8px,
  border-bottom 1px solid var(--border), margin-bottom 12px

───────────────────────────────────────────────
MOTION — HARD RULES
───────────────────────────────────────────────

Allowed (complete list):
  background-color / border-color / color:  120ms ease
  opacity (show/hide panels):               100ms ease
  transform: scale() (button active only):  80ms ease
  width (progress bar):                     80ms linear
  max-height (accordion open/close):        200ms ease
  outline (focus ring):                     80ms ease

BANNED — any of these = rejected output:
  ✗ keyframe @animation on layout or content elements
  ✗ translateY / translateX entrance effects
  ✗ Staggered animation-delay on grid items
  ✗ Hover float: transform translateY(-Xpx)
  ✗ Pulse / glow / shimmer on non-skeleton elements
  ✗ Scroll-triggered animations
  ✗ Page transition effects
  ✗ border-left/right/top/bottom used as decorative accent line
  ✗ Gradient on any container or text
  ✗ background-clip: text
  ✗ backdrop-filter: blur (glassmorphism)
  ✗ box-shadow on cards, buttons, or inputs (only on floating panels)

Skeleton loading:
  bg var(--bg-hover), border-radius 4px
  Single opacity animation: 0.5 → 0.8, 1.4s ease-in-out infinite alternate
  No shimmer. No sweep.

───────────────────────────────────────────────
ACCESSIBILITY — MANDATORY, NOT OPTIONAL
───────────────────────────────────────────────

Every interactive element:
  - Keyboard focusable, logical tab order
  - Visible focus ring: outline 2px solid var(--accent), outline-offset 2px
  - Focus ring NEVER removed with outline:0 unless replaced with equivalent
  - :focus-visible used instead of :focus where appropriate

ARIA requirements:
  - Icon-only buttons: aria-label with descriptive text
  - File inputs: <label> explicitly associated via htmlFor
  - Progress bars: role="progressbar" aria-valuenow aria-valuemin aria-valuemax
  - Custom selects: role="combobox" / "listbox" / "option" full pattern
  - Accordion (FAQ): role="region", aria-expanded, aria-controls
  - Error messages: role="alert" or aria-live="polite"
  - Nav dropdown: aria-haspopup="true", aria-expanded state

Color independence:
  - Never convey information through color alone
  - Strength meter: color + text label + icon
  - Error state: border color + error message text below input
  - Success state: icon + text, not just green color

Text:
  - Minimum font-size 12px (0.75rem) anywhere in UI
  - Line-height minimum 1.4 for body text
  - No text on images without contrast overlay
  - Disabled state: opacity 0.4 + cursor: not-allowed, never just grayed text
    without pointer-events indication

Reduced motion:
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
    }
  }

Touch targets:
  Minimum 44px × 44px for all interactive elements on mobile.
  Inputs, buttons, dropdown triggers all meet this minimum.
