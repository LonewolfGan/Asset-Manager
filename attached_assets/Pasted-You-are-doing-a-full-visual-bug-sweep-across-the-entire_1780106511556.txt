BUG 1 — Range slider: thumb not centered, sitting at the bottom
The range input thumb (<input type="range">) is vertically misaligned —
it appears at the bottom of the track instead of centered on it.
Root cause: missing vertical alignment CSS on the range input and its thumb.
Fix — apply globally to all range inputs:
cssinput[type="range"] {
  /* Reset browser defaults that cause alignment issues */
  -webkit-appearance: none;
  appearance: none;
  width: 100%;
  height: 4px;                          /* track height */
  background: var(--border);         
  border-radius: 2px;
  outline: none;
  cursor: pointer;
  /* CRITICAL — this fixes the vertical alignment */
  vertical-align: middle;
  margin: 0;
  padding: 0;
}

/* Track — WebKit (Chrome, Safari, Edge) */
input[type="range"]::-webkit-slider-runnable-track {
  height: 4px;
  background: var(--border);
  border-radius: 2px;
  /* Center the track vertically */
  display: flex;
  align-items: center;
}

/* Thumb — WebKit */
input[type="range"]::-webkit-slider-thumb {
  -webkit-appearance: none;
  appearance: none;
  width: 18px;
  height: 18px;
  border-radius: 50%;
  background: var(--accent);            
  border: 2px solid var(--bg);         /* creates a clean ring */
  cursor: pointer;
  /* CRITICAL — this is what centers the thumb on the track */
  margin-top: -7px;                     /* (thumb height - track height) / 2 = (18 - 4) / 2 = 7 */
  box-shadow: 0 0 0 0 transparent;
  transition: box-shadow 0.15s;
}

input[type="range"]::-webkit-slider-thumb:hover {
  box-shadow: 0 0 0 6px rgba(212, 255, 79, 0.15);
}

input[type="range"]::-webkit-slider-thumb:active {
  box-shadow: 0 0 0 8px rgba(212, 255, 79, 0.2);
}

/* Track — Firefox */
input[type="range"]::-moz-range-track {
  height: 4px;
  background: var(--border);
  border-radius: 2px;
  border: none;
}

/* Thumb — Firefox */
input[type="range"]::-moz-range-thumb {
  width: 18px;
  height: 18px;
  border-radius: 50%;
  background: var(--accent);
  border: 2px solid var(--bg);
  cursor: pointer;
  box-shadow: none;
}

/* Fill color left of thumb — Firefox */
input[type="range"]::-moz-range-progress {
  background: var(--accent);
  height: 4px;
  border-radius: 2px;
}

/* Focus state */
input[type="range"]:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 4px;
}

/* Wrapper — if the range is inside a flex or grid container */
.range-wrapper {
  display: flex;
  align-items: center;     /* centers range with any label beside it */
  gap: 0.75rem;
  width: 100%;
}
Apply this CSS to the global stylesheet. Verify it fixes the range on:

Compress Image (quality slider)
Compress PDF (compression level if using range)
Resize Image (percentage slider)
Password Generator (length slider)
Any other tool using <input type="range">

For the filled track effect (progress fill left of thumb) in WebKit —
this requires JavaScript since WebKit doesn't support ::-webkit-slider-progress:
javascript// Add to every range input on mount
const updateRangeFill = (input) => {
  const min = parseFloat(input.min) || 0
  const max = parseFloat(input.max) || 100
  const val = parseFloat(input.value)
  const pct = ((val - min) / (max - min)) * 100
  input.style.background = `linear-gradient(to right, var(--accent) ${pct}%, var(--border) ${pct}%)`
}

document.querySelectorAll('input[type="range"]').forEach(input => {
  updateRangeFill(input)
  input.addEventListener('input', () => updateRangeFill(input))
})
