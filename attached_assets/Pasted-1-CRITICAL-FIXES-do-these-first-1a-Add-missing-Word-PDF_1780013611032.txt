Create a new "Excel & Spreadsheets" category in the navigation. Add the following tools:
Excel to PDF /excel-to-pdf

Accept .xlsx and .xls
Render the spreadsheet and export as PDF
Use SheetJS (xlsx) to read the file and jsPDF or html2canvas to export

Excel to CSV /excel-to-csv

Accept .xlsx
Use SheetJS to parse and export as .csv
Allow selecting which sheet to export if the file has multiple sheets

CSV to Excel /csv-to-excel

Accept .csv
Use SheetJS to convert and export as .xlsx

CSV to JSON + JSON to CSV /csv-to-json

Two modes in one page (tab switcher)
CSV → paste or upload → output JSON
JSON → paste or upload → output CSV
Use PapaParse for CSV parsing

CSV Viewer /csv-viewer

Upload or paste a CSV
Display as a clean sortable HTML table
Show row count, column count
Allow downloading back as CSV
